# CourtTime Hub

"Create a modern, high-energy landing page for 'CourtTime', an AI-powered basketball sports analytics and court booking platform. Use a dark theme with vibrant accents (neon blue and energetic orange). Include a Hero section with a bold headline, key features highlighting AI shot tracking, player speed analytics, and court reservations. Add interactive cards for feature previews and clear Call-to-Action buttons for 'Get Started' and 'Book a Court'."                                                     "Design an analytics dashboard for CourtTime. Include visual metric cards for key player stats (Shot Accuracy %, Max Speed, Vertical Jump), an interactive basketball court layout showing a shooting heatmap, a line chart tracking performance over recent games, and a sidebar for navigation (Dashboard, Bookings, Profile, Matchmaking)."                                                 "Create a court booking page for CourtTime. Include a search bar with filters (Location, Indoor/Outdoor, Price range), a list/grid of available basketball courts with high-quality image placeholders, ratings, available time slots, and an interactive modal to confirm a booking."                                 "Build a player profile page featuring a user avatar, player tier/rank badge, overall skill attributes summary, match history list with scores, and an achievements panel."
